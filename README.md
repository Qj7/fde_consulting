# FDE Consulting

Лендинг українською на базі [Creative Tim UI](https://github.com/creativetimofficial/ui) (shadcn/ui blocks) із зеленою темою.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте http://127.0.0.1:5173/

## Стек

- Vite + React + TypeScript
- Tailwind CSS v4
- Creative Tim / shadcn UI components (`Button`, `Card`, `Badge`, `Avatar`, …)
- Блоки за патернами CT: Hero, Services, Testimonials, Team, FAQ, Contact, Footer
